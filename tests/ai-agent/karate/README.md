Đặt `karate-1.5.2.jar` (hoặc bản `karate-*.jar` khác) vào thư mục này. `run_karate.py` tự tìm file jar ở đây.

Thư mục này chỉ cần thêm file khi dự án muốn ghi đè `karate-config.js` hoặc hàm dùng chung có sẵn trong skill (`.agents/skills/api-test-design/assets/karate/`). File ở đây được ưu tiên hơn bản trong skill.
