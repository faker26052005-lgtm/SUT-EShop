Bước 1. Đối chiếu KẾ HOẠCH ở lượt đầu với CODE đã viết ở hai lượt trước. Lập bảng: mỗi mã test trong kế hoạch, có trong code chưa (Có hoặc Không).
Bước 2. Đối chiếu bảng phủ: liệt kê mọi endpoint, mọi mã FR và SEC, mọi mục OWASP áp dụng được mà chưa có test trong code, và mọi endpoint chưa đủ một test đường đi đúng cùng một test âm tính hoặc bảo mật.
Bước 3. Viết code cho TẤT CẢ test còn thiếu (các test có trong kế hoạch nhưng chưa có trong code, và các test bổ sung cho mục còn thiếu ở Bước 2), đặt trong hàm: async function aiTestsPart3(ctx) { ... } Không lặp lại code đã có.
Bước 4. Viết lại hàm tổng: async function aiTests(ctx) { await aiTestsPart1(ctx); await aiTestsPart2(ctx); await aiTestsPart3(ctx); }
