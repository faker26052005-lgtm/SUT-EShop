# Agent Skill

Mục tiêu: rút quy trình Domain Testing + BVA thành một Skill dùng lại được cho feature khác.

Gợi ý nội dung `SKILL.md` (làm sau khi hoàn thành một feature trọn vẹn):
- Đầu vào: đoạn SRS + API spec của feature.
- Các bước: trích yêu cầu → biến → lớp tương đương → test case Domain Testing → biên → test BVA → test nghiệp vụ/bảo mật → bảng gap.
- Quy tắc: mỗi test một vi phạm; chỗ SRS im lặng ghi CẦN LÀM RÕ; kiểm tra tác dụng phụ.
- Đầu ra: các file Markdown tương ứng với `templates/feature/`.

Đặt skill vào `skills/<tên-skill>/SKILL.md`, kèm link video demo YouTube ở `README.md`.
